KNOWN TRAPS (each one cost hours already)
T1. vite.config.ts main-process rollupOptions.external MUST contain "ffmpeg-static", "uiohook-napi", "@electron/llm", "node-llama-cpp". Any npm package that does its own runtime path resolution, native loading or preload injection must be added there, otherwise it gets inlined into dist-electron/main.cjs and breaks (symptom: contextBridge crash at startup, window.<x> undefined).
T2. SettingsPanel.tsx has two near-identical names: captionSectionContent (singular, per-cue only) and captionsSectionContent (plural, the real Captions tab). New captions UI goes in the PLURAL one.
T3. startNativeScreenRecording(source, options) takes TWO arguments. Merging into one object silently records no audio.
T4. Editor windows deny camera/mic (NotAllowedError); only the HUD window (title "Screenly") may use them. The HUD live webcam preview only streams when no editor window exists (getEditorMode() false) - by design.
T5. CDP target ids change every time a window opens/closes (stopping a recording swaps HUD for editor). Re-run curl -s localhost:9333/json before every script. Closing the last window leaves the process running with no windows; run: open REPO/release/mac-arm64/Screenly.app to recreate the HUD. Close a window through the browser websocket from curl localhost:9333/json/version using Target.closeTarget.
T6. Editor window can get stuck after many video loads ("Failed to load video (format not supported)" for valid files): fully restart: pkill -9 -f "Screenly.app" then relaunch. There is a single-instance lock; a stale process can silently keep old code running: always pkill before relaunch after a rebuild.
T7. Always set a socket timeout in websocket scripts. A hang usually means a blocking macOS dialog (camera/mic/screen-recording permission): take a screenshot and look.
T8. Recording audio is off unless requested in options (capturesSystemAudio / capturesMicrophone).
T9. electron-builder codesign error "A timestamp was expected but was not found" is a transient network flake: rerun the build. Do not run npm install while a build runs. Confirm a background build finished with ps -p <PID>, never with pgrep -f electron-builder (it matches its own wrapper).
T10. Shell prints a harmless "zoxide: detected a possible configuration issue" banner; ignore it, and never feed raw command output to a JSON parser without removing it.
T11. There is no system ffmpeg. Use REPO/node_modules/ffmpeg-static/ffmpeg (and ffprobe on PATH). SVG to PNG: qlmanage -t -s 1024 -o <outdir> <file.svg>. PIL/Pillow and numpy are installed for image generation.
T12. Never trust a source-only grep for "is X gone/present" in the built app; check the built bundle: strings release/mac-arm64/Screenly.app/Contents/Resources/app.asar | grep -c <text>.
